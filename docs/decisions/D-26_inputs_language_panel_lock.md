## D-26.1 ภาษาของหน้า Inputs (ไทยและอังกฤษ)
- ทุก input มี 2 ชุดป้าย: ภาษาไทย (ค่าเริ่มต้น) และอังกฤษ (เปิดด้วย `#define INPUT_LANG_EN`)
- ชื่อตัวแปร ชนิด ค่าเริ่มต้น และลำดับ ต้องเหมือนกันทั้งสองชุด เพราะไฟล์ .set ผูกตามชื่อตัวแปร ห้ามต่างกัน
- ป้ายอังกฤษใช้รูปแบบ `<ชื่อตัวแปร> - <คำอธิบาย>` เพื่อให้ตรงกับคู่มือทดสอบ ป้ายไทยไม่ต้องมีชื่อตัวแปร
- ป้ายของสมาชิก enum ต้องแปลทั้งสองชุดด้วย
- Core: ป้ายไทยอยู่ใน `Core_Inputs.mqh` (ส่วน `#else`) ป้ายอังกฤษอยู่ใน `Core_InputsEN.mqh` เพิ่ม input ใหม่ใน Core ต้องแก้ทั้งสองไฟล์ในครั้งเดียว
- กลยุทธ์: ใน `<ชื่อกลยุทธ์>_Inputs.mqh` ครอบแต่ละบรรทัดด้วย `#ifdef INPUT_LANG_EN ... #else ... #endif`
- ไฟล์ EA ของแต่ละกลยุทธ์มี 3 ไฟล์ใน `Strategies/<ชื่อ>/v<เวอร์ชัน>/`:
  - `<ชื่อ>_EA.mq5` ต้นฉบับโค้ดจริง (ไม่มี `#define INPUT_LANG_EN` ภายในไฟล์นี้เด็ดขาด)
  - `<ชื่อ>_EA_EN.mq5` ใช้ทดสอบ: `#property` + `#define INPUT_LANG_EN` + `#include "<ชื่อ>_EA.mq5"`
  - `<ชื่อ>_EA_TH.mq5` ใช้เทรดจริง: `#property` + `#include "<ชื่อ>_EA.mq5"`
- ทดสอบใช้ `_EN` เทรดจริงใช้ `_TH` ส่วน `<ชื่อ>_EA` ใช้เป็นต้นฉบับ ไม่แนบบนกราฟ
- เครื่องมือ `verify_core` และ `next_magic` หากลยุทธ์จากชื่อ `<ชื่อ>_EA.mq5` เท่านั้น ห้ามเปลี่ยนชื่อไฟล์ต้นฉบับ
- ภาษาสลับตอนรันไม่ได้ ถูกกำหนดตอนคอมไพล์

## D-26.2 Panel ปรับขนาดอัตโนมัติ
- 4 ระดับ: L (เต็ม 430x360), M, S, XS (ย่อ) เลือกจากความกว้างและความสูงกราฟ ใหญ่สุดที่ใส่พอ
- เกณฑ์ความสูงกราฟ: Lock ปิด L >= 394 / M >= 300 / S >= 226 / ต่ำกว่านั้น XS | Lock เปิด M >= 312 / S >= 256
- กว้าง < 330 px = XS กว้าง 330-519 px = โหมดแคบ (Panel กว้าง 300-360 ข้อความย่อ)
- ตัวสร้าง Panel อยู่ใน `Core_PanelLayout.mqh` ค่าคงที่ระดับอยู่ใน `Core_Panel.mqh` (ใช้ `#ifndef`) ไม่เพิ่มในธีม `CoreUI_Theme.mqh` (ล็อก)
- ชื่อ Object ของ Panel (BG, HDR, MIN, B_PWR, N_*/V_*, SB1-3, B_CLBUY, B_CLSELL, B_REFILL, B_RESET, B_CLALL, FOOT, LK1-3) ห้ามเปลี่ยน เพราะ `PanelUpdate` และตัวรับ Event ใช้ชื่อเหล่านี้ `PanelSet` ไม่ทำอะไรถ้า Object ไม่ถูกสร้างในระดับนั้น
- ทุกครั้งที่ระดับเปลี่ยน Log พิมพ์ `Panel tier=... | chart=กว้างxสูง | panel=กว้างxสูง` (พิมพ์เฉพาะตอนระดับเปลี่ยน)
- ปุ่มของกลยุทธ์สูงสุด 3 ปุ่ม (D-14) ถ้าสร้างสำเนา Panel เฉพาะกลยุทธ์ ต้องเปลี่ยน `#include "Core_PanelLayout.mqh"` เป็น `#include "../Core/include/Core_PanelLayout.mqh"` (ทดสอบแล้วใน C-10)

## D-26.3 Lock Profit (Core)
- Input `InpLockProfit` (ค่าเริ่มต้น false) เมื่อ false พฤติกรรมเหมือนเดิมทุกประการ
- เมื่อ true: ทุนเทรด = ทุนเริ่มต้น + REFILL + RESET + ขาดทุนสะสม กำไรไม่เพิ่มทุน คิดผลสุทธิต่อไม้ (Position) รวมคอมมิชชั่นและสวอป
- ฟังก์ชัน Core: `TryGetVirtualEquity` (กลยุทธ์ต้องใช้ฟังก์ชันนี้ ห้ามคำนวณทุนเอง), `TryGetLockStats`, `DoCapitalReset`, `GetRefillCount`, `GetResetCount`, `GetTotalReset`
- RESET เติมเฉพาะส่วนที่ขาดให้ทุนเทรดกลับเท่าทุนเริ่มต้น ข้ามถ้าทุนไม่ต่ำกว่าทุนเริ่มต้น ปุ่ม RESET แสดงเมื่อเปิด Lock เท่านั้น
- ยอด RESET เก็บถาวรต่อ Magic และนับรวมในสูตรทุนเสมอ แม้ปิด Lock ภายหลัง (มติ 2 พ.ย. 2026)
- State: ตัวแปรถาวรของ Terminal `<TAG>S_<บัญชี>_<Symbol>_<Magic>_RFCNT`, `_RESET`, `_RSCNT` (ตัวนับ REFILL, ยอด RESET, ตัวนับ RESET)
- Preset ตัวอย่าง: `SHORT_20_PROFIT_LOCK.set` (Magic 10020)

## D-26.4 ลำดับเมื่อแก้ Core
1. บันทึกไฟล์ 2. `sync_core.bat` 3. คอมไพล์ EA ทุกตัวของกลยุทธ์ (`_EA`, `_EN`, `_TH`) 4. `verify_core.bat` ต้อง ERROR 0 | WARN 0
- ห้ามคอมไพล์ก่อน sync เพราะ EA ใช้สำเนา Core ในโฟลเดอร์กลยุทธ์ จะได้โค้ดเก่า
- เพิ่ม Magic ใหม่ (รวม Magic ที่ใช้ทดสอบ): ลงทะเบียนใน `MAGIC_REGISTRY.md` ก่อน แล้วรัน `tools\next_magic.bat --apply` (ดับเบิลคลิกไฟล์ .bat คือโหมดดูอย่างเดียว) และคอมไพล์ใหม่ Magic ที่ใช้แล้วห้ามนำกลับมาใช้ซ้ำ
- ชื่อไฟล์ Preset: ผูกกับ Magic (เช่น SHORT_20 = 10020)
- เมื่อมี Core เวอร์ชันใหม่ (v1.0.1, v1.1) ดูนโยบายโฟลเดอร์เวอร์ชันใน `docs/handoff/HANDOFF_CORE_V1_1.md` ก่อนรัน sync_core เพราะเครื่องมือเลือก Core ล่าสุดและ sync ทุกสำเนาโดยอัตโนมัติ
