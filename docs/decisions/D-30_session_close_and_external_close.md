# D-30: Session Close และนับการปิดนอก EA เข้า Closed Net (ขยายขอบเขต Core v1.0.1)

วันที่: 18 พ.ย. 2026 | ผู้ใช้สั่ง (เลือกทางเลือก B: เพิ่มใน Core v1.0.1) | สถานะ: ข้อ 1 ทดสอบแล้ว (18 พ.ย. 2026) ข้อ 2 ทดสอบแล้ว (18 พ.ย. 2026 ยกเว้น CSV)

## ที่มา
- Session เดิมบล็อกเฉพาะการเปิดรอบใหม่อัตโนมัติ ไม้ที่ค้างอยู่ไม่ถูกปิด (เช่นไม้ XAG ที่ค้างข้าม rollover แล้วเสีย swap)
- Closed Net และ Virtual Equity นับเฉพาะดีลที่ Magic ตรงกับ EA ดีลปิดด้วยมือจาก Toolbox มือถือ หรือเว็บ มี Magic เป็น 0 จึงไม่ถูกนับ

## 1. Session Close
1. เพิ่ม Input `InpSession1Close`, `InpSession2Close`, `InpSession3Close` (bool ค่าเริ่มต้น false) หนึ่งตัวต่อหนึ่งช่วง ไม่มีตัวรวม
2. ทำงานเฉพาะช่วงที่เปิดบล็อกอยู่ (`InpSession1Block` ถึง `InpSession3Block` เป็น true) ถ้าเปิด Close แต่ไม่เปิดบล็อก ตัวเลือกไม่ทำงานและมี Log เตือนตอนเริ่ม EA
3. ตอนเข้าช่วง เรียก Strategy_CloseAll("SESSION-CLOSE") ปิดไม้ทั้งสองฝั่งพร้อมกัน แล้วตรวจ Position จริงว่า Basket ว่าง ถ้าปิดไม่หมดลองใหม่ทุก 5 วินาที
4. ปิดครั้งเดียวต่อช่วง เก็บรหัสช่วง (เวลาเริ่มช่วง) ใน GlobalVariable ชื่อลงท้าย SC1 ถึง SC3 รีสตาร์ท EA ไม่ปิดซ้ำ
5. ถ้า Basket ว่างอยู่แล้วตอนเข้าช่วง = บันทึกว่าจัดการแล้ว ไม้ที่เปิดด้วยปุ่ม HEDGE OPEN ทีหลังในช่วงเดียวกันไม่ถูกปิด
6. ถ้า EA เริ่มทำงานกลางช่วงที่ยังไม่ได้จัดการ และมีไม้ค้างอยู่ จะปิดทันที
7. ทำงานแม้ปุ่ม ON/OFF (D-13) เป็น OFF เพราะ OFF ห้ามเปิดใหม่ ไม่ได้ห้ามปิด
8. เวลาเป็นเวลาเซิร์ฟเวอร์เหมือน Session เดิม พ้นช่วงบล็อกแล้ว Hedge เปิดรอบใหม่ตามเงื่อนไขเดิม (InpReopenOnEmpty, Timeout, สเปรด, ทุน)
9. ค่าเริ่มต้นปิดทั้งหมด พฤติกรรมเดิมไม่เปลี่ยน

## 2. นับการปิดนอก EA (ทดสอบแล้ว ยกเว้น CSV)
1. เพิ่ม Input `InpCountExternalClose` (bool ค่าเริ่มต้น true)
2. เมื่อเปิด Closed Net และสถิติ Lock Profit นับทุกดีลของ Position ที่ดีลเปิดเป็นของ EA นี้ (Magic และ Symbol ตรง) รวมดีลปิดที่ Magic เป็น 0 รายงาน CSV ใช้หลักเดียวกัน
3. เมื่อปิด นับแบบเดิม (กรองด้วย Magic ทุกดีล)
4. วิธีนับ: อ่านประวัติทั้งหมดรอบแรกเพื่อเก็บ Position ID ของไม้ที่ดีลเปิดเป็นของ EA นี้ แล้วรอบที่สองนับทุกดีลของ Position เหล่านั้น
5. ไม่นับ Position ที่เปิดมือหรือ EA อื่นเปิด แม้ Symbol เดียวกันและปิดด้วย Magic เป็น 0 เหมือนกัน
6. ผลต่อทุน: ปิดนอก EA ขาดทุน Virtual Equity ลดลงและ Lot ตามบันได (InpAutoLot) อาจลดลงด้วย ถ้ากำไร Lot อาจเพิ่ม
7. ใช้กับ Closed Net, สถิติ Lock Profit และ CSV รายงาน (ClosedPL, ClosedTrades, TradedLots)
8. ผลคำนวณเก็บแคชตามจำนวนดีลในประวัติ (รวมสถานะ InpCountExternalClose) ไม่วนประวัติซ้ำทุก Tick
9. ข้อจำกัด: ถ้าเปลี่ยน Magic ระหว่างทาง ดีลของ Magic เก่าไม่นับ เหมือนเดิม
