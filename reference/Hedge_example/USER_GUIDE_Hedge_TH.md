# Hedge 1.0 (v1.0.1) คู่มือใช้งานแบบเข้าใจง่าย

คู่มือนี้เขียนสำหรับคนที่ไม่ได้เขียนโปรแกรม อธิบายว่า "แต่ละปุ่ม แต่ละช่องตั้งค่า แต่ละข้อความบนหน้าจอ คืออะไร และควรใช้ตอนไหน" พร้อมสถานการณ์จำลองให้เห็นภาพ

ตัวเลขทั้งหมดในตัวอย่างเป็นตัวเลขสมมติ ใช้ค่าเริ่มต้นของโปรแกรมกับทอง XAUUSD ที่ 0.01 Lot เพื่อให้เห็นภาพเท่านั้น ไม่ใช่ผลการเทรดจริง และไม่ใช่คำแนะนำการลงทุน

ผมทำคู่มือผู้ใช้ภาษาไทยสำหรับ Hedge v1.0.1 เป็นไฟล์ Markdown เขียนให้คนไม่เขียนโปรแกรมอ่านได้ อธิบายทุก Input ทุกช่องและปุ่มบน Panel และมีสถานการณ์จำลอง 13 เรื่อง ผมเขียนจากโค้ดและเอกสารที่ commit ล่าสุด ส่วนไฟล์นี้ยังไม่ได้ตรวจด้วย `check_docs`

## ในไฟล์มีอะไร

1. **สรุป 1 นาทีและคำศัพท์:** ตะกร้า รอบ Magic Point (1,000 Points = $10 ต่อไม้ที่ 0.01 Lot บนทอง) ทุนเสมือน และเวลาเซิร์ฟเวอร์
2. **ภาพรวมหนึ่งรอบ:** ลำดับตั้งแต่ประตู 6 ข้อ เปิดคู่ ตรวจจริง ไปจนระบบป้องกัน 4 ขั้น (Cut Loss, R:R, Trailing TP, Break-even)
3. **Panel ทีละช่อง:** กลุ่ม STATUS, LOT & CAPITAL, POSITIONS ทุกปุ่ม ตารางอ่านแถว Entry (READY, WAIT_SPREAD, CAPITAL_DEAD ฯลฯ พร้อมสิ่งที่ต้องทำ) และขนาด Panel ที่ย่อตามกราฟ
4. **Input ทุกตัว:** ตารางต่อกลุ่ม มีค่าเริ่มต้น คำอธิบายง่ายๆ และ "ปรับเมื่อไหร่" รวม Input ใหม่ของ v1.0.1 (`InpSessionNClose`, `InpCountExternalClose`)
5. **สถานการณ์จำลอง 13 เรื่อง:** เริ่มใช้ครั้งแรก, รอบกำไรพร้อมตารางเหตุการณ์ทีละขั้น, รอบแกว่ง, พัก OFF, ทุนหมดแล้ว REFILL, สเปรดกว้าง, Session Block, Session Close, ปิดนอก EA, Lock Profit, โหมดมือ, รีสตาร์ท, และรายงาน CSV
6. **ตาราง "อยากทำอะไร ใช้อะไร", วิธีอ่าน Log และข้อจำกัด**

## สิ่งที่ควรรู้ก่อนใช้

- ตัวเลขในตัวอย่างเป็นตัวเลขสมมติจากค่าเริ่มต้น ไม่รวมสเปรด และการเลื่อน SL ของ Break-even ผมระบุว่า "ประมาณ"
- แถว `Loss` ในโหมด Lock Profit ผมสรุปจากตัวเลขบน Panel ที่คุณส่งมา (ทุนเริ่มต้นลบ Trading Cap) ไม่ได้อ่านจากโค้ดตรงๆ จึงเขียนกำกับไว้ในไฟล์
- ส่วนที่ยังไม่ทดสอบ (CSV เทียบ Closed Net, ปิดไม่หมดแล้วลองใหม่, ช่วงข้ามเที่ยงคืนบนกราฟ) ระบุไว้ในหัวข้อข้อจำกัดแล้ว
- ที่เก็บแนะนำ: `Strategies/Hedge/doc/USER_GUIDE_Hedge_TH.md` (คนละไฟล์กับ `Strategies/Hedge/doc/README.md` ซึ่งเป็นฉบับนักพัฒนา) หลังวางแล้วรัน `check_docs` ถ้าขึ้นคำเตือน ส่งบรรทัดมาแก้ได้

## 0. อ่านก่อน 1 นาที

- **Hedge ทำอะไร:** ทุกครั้งที่ไม่มีออเดอร์ค้างอยู่ จะเปิด Buy 1 ไม้ และ Sell 1 ไม้ ขนาดเท่ากัน พร้อมกัน แล้วให้ระบบป้องกันคอยดูแลแต่ละไม้ (ตัดขาดทุน ล็อกกำไร ปิดเมื่อถึงเป้า)
- **ไม่รับประกันกำไร:** ตลาดแกว่งแคบๆ ต่อเนื่อง จะขาดทุนค่าสเปรดและ SL ซ้ำๆ ได้
- **ใช้บัญชี Demo ก่อนเสมอ** และรองรับเฉพาะบัญชีแบบ Hedging
- **ค่ามาตรฐานตั้งไว้สำหรับทอง XAUUSD** ถ้าใช้สัญลักษณ์อื่นต้องปรับ `InpPointDigits` และระยะ Points เอง
- **ห้ามแนบ EA สองตัวที่ Magic เดียวกัน** (v1.0.1 มีตัวป้องกัน ตัวที่แนบทีหลังจะไม่ทำงาน)
- เอกสารฉบับนักพัฒนาอยู่ที่ `Strategies/Hedge/doc/README.md` ฉบับนี้เน้นการใช้งานจริง

### คำศัพท์ที่ใช้บ่อย

| คำ | ความหมายง่ายๆ |
|---|---|
| ตะกร้า (Basket) | ออเดอร์ทั้งหมดของ EA ตัวนี้ (ตาม Magic และคู่เงินนี้) |
| รอบ (Cycle) | ตั้งแต่เปิดคู่ Buy+Sell จนตะกร้าว่าง |
| Magic | เลขประจำตัวของ EA แต่ละตัว ใช้แยกออเดอร์ของบอทออกจากออเดอร์อื่น |
| Point | หน่วยราคาเล็กๆ ของทอง 1 Point = 0.01 ราคา ดังนั้น 1,000 Points = ราคาเคลื่อน $10 (ที่ 0.01 Lot ได้หรือเสียประมาณ $10 ต่อไม้) |
| ทุนเสมือน (Virtual Equity) | ทุนที่บอทนับเอง ไม่ใช่ยอดเงินในบัญชีจริง ใช้คำนวณขนาด Lot |
| Closed Net | กำไรขาดทุนสุทธิของไม้ที่ปิดไปแล้วทั้งหมดของ Magic นี้ (ไม่รวมกำไรลอยตัว) |
| SL | ราคาตัดขาดทุนอัตโนมัติ ติดไปกับออเดอร์ตั้งแต่เปิด |
| เวลาเซิร์ฟเวอร์ | เวลาของโบรกเกอร์ ดูได้ที่มุมซ้ายบนของหน้าต่าง Market Watch (บางโบรกเกอร์ไม่ตรงกับเวลาเครื่อง) |

## 1. ภาพรวม: หนึ่งรอบทำงานอย่างไร

```text
ตะกร้าว่าง
   |
   v
รอผ่านประตู 6 ข้อ (ข้อไหนไม่ผ่าน หน้าจอแถว Entry จะบอกเหตุผล)
   ON/OFF -> รายงานค้าง -> ทุนพอ -> ไม่อยู่ในช่วงห้ามเข้า -> รอครบ Timeout -> สเปรดไม่สูง
   |
   v
เปิดคู่ Buy+Sell (พร้อม SL ทั้งสองไม้)
   |
   v
ตรวจจริงว่ามี Buy 1 ไม้ Sell 1 ไม้ Lot เท่ากัน
   (ถ้าไม่ครบ: ลองเปิดฝั่งที่หายอีกไม่เกิน 3 ครั้ง ถ้ายังไม่ครบ ปิดทิ้งทั้งหมดแล้วพัก 60 วินาที)
   |
   v
ระบบป้องกันดูแลแต่ละไม้ทุกครั้งที่ราคาขยับ
   ไม้ใดชน SL หรือถึงเป้าก็ปิดไปเอง
   |
   v
ตะกร้าว่างอีกครั้ง -> กลับไปบนสุด (ถ้า InpReopenOnEmpty เป็น true)
```

กฎสำคัญ "หนึ่งตะกร้าเท่านั้น": ถ้าเหลือไม้ค้างแค่ขาเดียว Hedge จะไม่เปิดขาที่หายไปคืน และไม่เปิดคู่ใหม่ซ้อน ต้องรอให้ปิดหมดก่อน (หน้าจอจะขึ้น `WAIT_BASKET_EMPTY`)

### ระบบป้องกันต่อไม้ (ทำตามลำดับทุก Tick)

| ลำดับ | ชื่อ | ทำอะไร | ค่าเริ่มต้น (ตัวอย่างทอง 0.01 Lot) |
|---|---|---|---|
| 1 | Cut Loss | ตั้ง SL ห่างจากราคาเข้า | 1,000 Points (ประมาณ $10 ต่อไม้) |
| 2 | R:R | ปิดทำกำไรเมื่อถึงเป้า | 200% ของ Trigger = ปิดที่ +2,000 Points (ประมาณ +$20) |
| 3 | Trailing TP | เริ่ม "จับกำไร" เมื่อกำไรถึง Cut Loss + Pullback แล้วปิดเมื่อราคาย้อนจากจุดสูงสุดครบ Pullback | เริ่มที่ +1,500 ปิดเมื่อย้อน 500 Points จากจุดสูงสุด |
| 4 | Break-even | เมื่อกำไรถึง Trigger เลื่อน SL มาล็อกกำไรบางส่วน | Trigger 1,000 Points ล็อก 20% ของกำไร โหมดเลื่อนตามทุก 100 Points |

ระบบป้องกันทำงานต่อเสมอ แม้ปุ่ม ON/OFF เป็น OFF หรืออยู่ในช่วง Session ห้ามเข้า

## 2. หน้าจอ Panel: ทุกช่องแปลว่าอะไร

Panel อยู่บนกราฟ หัวบอกชื่อกลยุทธ์ คู่เงิน และเลข Magic เช่น `Hedge 1.0 | XAUUSD [1000011]`

### 2.1 ปุ่มมุมบนขวา

| ปุ่ม | ทำอะไร | ใช้ตอนไหน |
|---|---|---|
| ON / OFF | OFF = หยุดเปิดออเดอร์ใหม่ทุกทาง (รวมปุ่ม HEDGE OPEN) แต่ยังดูแลและปิดไม้ที่ค้างอยู่ จำสถานะไว้แม้รีสตาร์ท | อยากพักเปิดรอบใหม่ เช่น ก่อนข่าวแรง แต่ไม่อยากปิดไม้ที่ถืออยู่ |
| `-` / `+` | ย่อ/ขยายรายละเอียดบน Panel | กราฟแคบ อยากเห็นกราฟมากขึ้น |

ปุ่ม ON/OFF เป็นสีเทาเมื่อ EA เทรดไม่ได้ (เช่น ปุ่ม Algo Trading ปิดอยู่) ชี้เมาส์เพื่อดูเหตุผล

### 2.2 กลุ่ม STATUS (สถานะประตูเปิดรอบ)

| แถว | ความหมาย | ตัวอย่าง |
|---|---|---|
| Session | OPEN = เปิดรอบได้ / BLOCK = อยู่ในช่วงห้ามเปิดรอบอัตโนมัติ | `OPEN` |
| Spread | สเปรดตอนนี้ (Points) / เพดานที่ตั้ง (Trigger) และสถานะตรวจสเปรด ON หรือ OFF | `33 / Trigger 25 (ON)` |
| Refill Timer | วินาทีที่เหลือ / เวลา Timeout ทั้งหมด ชื่อบนจอคือ Refill Timer แต่ทำหน้าที่ "รอก่อนเปิดรอบใหม่หลังตะกร้าว่าง" | `296 / 300 sec (ON)` |

### 2.3 กลุ่ม LOT & CAPITAL (ทุนและขนาด Lot)

| แถว | ความหมาย |
|---|---|
| Base Lot | Lot เริ่มต้นที่ตั้งไว้ |
| Lot Step | เพิ่ม Lot เท่าไรต่อทุกกี่ดอลลาร์ และตอนนี้อยู่ขั้นที่เท่าไร เช่น `+0.01 / $50 (step 1)` |
| Effective Lot | Lot ที่จะใช้เปิดรอบถัดไปจริง (คำนวณจากทุนเสมือน) |
| Virtual Equity | ทุนเสมือนปัจจุบัน = ทุนเริ่มต้น + REFILL + RESET + กำไรขาดทุนที่ปิดแล้ว (ถ้าเปิด Lock Profit แถวนี้ใช้ชื่อ Trading Cap) |
| Closed Net | กำไรขาดทุนสุทธิที่ปิดแล้วทั้งหมด รวมค่าคอมมิชชั่นและสวอป รวมการปิดนอก EA เมื่อเปิด `InpCountExternalClose` |
| Cycle Loss | ผลของรอบปัจจุบัน นับจากตอน `CYCLE START` (ถ้าเปิด Lock Profit แถวนี้ใช้ชื่อ Locked Profit = ผลรวมกำไรที่ล็อกไว้ ไม่เข้าทุนเทรด) |

### 2.4 กลุ่ม POSITIONS (ไม้ที่ถืออยู่)

| แถว | ความหมาย |
|---|---|
| Open Floating | กำไรขาดทุนลอยตัวของไม้ที่ค้าง |
| Active | จำนวนไม้ทั้งหมด / Buy กี่ไม้ / Sell กี่ไม้ เช่น `1  Buy:0  Sell:1` |
| Cut Loss Limit | ระยะ Cut Loss ที่ตั้งไว้ (Points) |
| Entry | เหตุผลที่ตอนนี้ยังไม่เปิดรอบใหม่ (ดูตารางข้อ 2.6) |

### 2.5 ปุ่มฝั่งขวา

| ปุ่ม | ทำอะไร | ใช้ตอนไหน |
|---|---|---|
| BUY LOCKED / SELL LOCKED | ถูกล็อก กดแล้วไม่เปิดไม้เดี่ยว (นโยบายเปิดเป็นคู่เท่านั้น) | ไม่ต้องกด |
| HEDGE OPEN (B+S) | เปิดคู่ Buy+Sell ด้วยมือทันที ข้ามเงื่อนไข Session, Timeout และสเปรด แต่ไม่ข้าม OFF, รายงานค้าง และทุนหมด | อยากเปิดรอบเองตอนนี้ หรือใช้โหมดมือ (`InpReopenOnEmpty = false`) |
| CLOSE BUY | ปิดไม้ Buy ทั้งหมดของ EA | อยากปิดเฉพาะขา Buy |
| CLOSE SELL | ปิดไม้ Sell ทั้งหมดของ EA | อยากปิดเฉพาะขา Sell |
| CLOSE ALL | ปิดทุกไม้ของ EA | อยากเลิกถือทั้งหมดตอนนี้ ใช้ได้ตลอด ไม่ถูก Session หรือ Timeout บล็อก |
| REFILL $N | เติมทุนเสมือนครั้งละ `InpRefillAmount` | ทุนหมด (ดูข้อ 4.5) |
| RESET | (เฉพาะเมื่อเปิด Lock Profit) เติมทุนเทรดให้กลับเท่าทุนเริ่มต้นในครั้งเดียว เติมเฉพาะส่วนที่ขาด | ใช้กับ Lock Profit เมื่อทุนเทรดลดลงแล้วอยากกลับไปที่ทุนเริ่มต้น |

ข้อควรจำ: ปุ่ม CLOSE BUY หรือ CLOSE SELL กดแล้วเหลือไม้ขาเดียว Hedge จะไม่เปิดขาที่หายคืน ต้องปิดให้หมดก่อนจึงเปิดรอบใหม่ได้

### 2.6 อ่านแถว Entry (ทำไมยังไม่เปิดรอบ)

| ข้อความ | ความหมาย | ต้องทำอะไร |
|---|---|---|
| READY | พร้อมเปิดรอบเมื่อตะกร้าว่าง | ไม่ต้องทำอะไร |
| WAIT_TIMEOUT | รอครบเวลา Timeout หลังตะกร้าว่าง | รอ |
| WAIT_SPREAD | สเปรดสูงกว่าที่กำหนด | รอสเปรดลง หรือปรับ `InpMaxSpreadPoints` |
| SESSION_BLOCK | อยู่ในช่วงห้ามเปิดรอบ | รอพ้นช่วง |
| CAPITAL_DEAD | ทุนเสมือน 0 หรือติดลบ | กด REFILL |
| CAPITAL_UNAVAILABLE | อ่านทุนไม่ได้ (ประวัติหรือสถานะผิดปกติ) | ดู Log ใน Experts |
| WAIT_REPORT | กำลังทำรายงานรอบ | รอให้ตะกร้าว่างและรายงานเสร็จ |
| PAUSED | ปุ่ม OFF | กด ON |
| AUTO_OFF | `InpReopenOnEmpty` เป็น false | ใช้ HEDGE OPEN หรือเปิด Input |
| QUOTA_DONE n/N | ใช้รอบอัตโนมัติครบตาม `InpMaxAutoRounds` แล้ว | รอช่วง Session Block สิ้นสุดเพื่อรีเซ็ต หรือกด HEDGE OPEN เปิดเอง |
| COOLDOWN | เปิดคู่ล้มเหลวเมื่อไม่นานมานี้ (พัก 60 วินาที) | รอ ดู Log |
| BASKET_RUNNING | มีทั้ง Buy และ Sell อยู่ | ไม่ต้องทำอะไร |
| WAIT_BASKET_EMPTY | เหลือไม้เดียว รอปิดหมดก่อนเปิดรอบใหม่ | รอ หรือกด CLOSE ALL |

### 2.7 บรรทัดล่างสุดของ Panel

บรรทัดเหลืองคือ Comment ของ EA เช่น `HDG10000 H1 base` ถ้าเปิด Lock Profit จะมีบรรทัดเพิ่ม: `Loss` (ทุนเริ่มต้นลบ Trading Cap ปัจจุบัน คำนวณจากตัวเลขที่เห็นบนแผง) จำนวนครั้งและยอดที่ REFILL และจำนวนครั้งและยอดที่ RESET

### 2.8 ขนาด Panel

Panel เลือกขนาดเองตามขนาดกราฟ (4 ระดับ) ถ้ากราฟเตี้ยหรือแคบ Panel จะย่อ: ระดับ M ซ่อนกลุ่ม STATUS, ระดับ S เหลือ 5 แถวหลัก (Virtual Equity, Closed Net, Open Floating, Active, Entry), ระดับเล็กสุดเหลือหัว ปุ่ม ON/OFF และ `+` ถ้าอยากเห็นครบ ให้ขยายหน้าต่างกราฟ

## 4. สถานการณ์จำลอง: ต้องใช้ฟังก์ชันไหน ตอนไหน

### 4.1 เริ่มใช้งานครั้งแรก

1. ใช้บัญชี Demo แบบ Hedging เปิดกราฟทอง XAUUSD เปิดปุ่ม Algo Trading ที่แถบเครื่องมือ
2. ลาก `Hedge_EA_TH` (หรือ `_EN`) ลงกราฟ ติ๊ก Allow Algo Trading ในแท็บ Common
3. แท็บ Inputs ตั้ง `InpMagicNumber` ไม่ให้ซ้ำ และ Comment ขึ้นต้นด้วย `HDG<Magic>` ถ้าเปิด `InpIdentityCheck` กด OK
4. ดู Panel ต้องเห็นหัว Hedge 1.0 และ Entry เป็น `WAIT_TIMEOUT` แล้วเป็น `READY`
5. ดูแท็บ Experts ต้องมี `เริ่มระบบสำเร็จ` และ `Strategy=Hedge 1.0 v1.0.1`

ถ้าไม่ผ่าน: EA ไม่ขึ้นข้อความเริ่มระบบ แปลว่าตรวจ Input ไม่ผ่านหรือบัญชีไม่ใช่แบบ Hedging ดูข้อความ Alert

### 4.2 รอบปกติที่ได้กำไร (ตัวเลขสมมติ ใช้ค่าเริ่มต้น ไม่รวมสเปรดและคอมมิชชั่น)

| ลำดับ | เหตุการณ์ | ผลต่อไม้ |
|---|---|---|
| 1 | ราคา 3800.00 ระบบเปิด Buy + Sell | SL ของ Buy ที่ 3790.00 SL ของ Sell ที่ 3810.00 |
| 2 | ราคาขึ้นไป 3810.00 | Sell ชน SL ปิด -$10 ส่วน Buy กำไร +$10 ถึง Trigger ของ Break-even ระบบเลื่อน SL ของ Buy ขึ้นมาล็อกกำไรบางส่วน |
| 3 | ราคาไป 3815.00 (+1,500 Points) | Trailing TP เริ่มทำงาน (Armed) |
| 4 | ราคาสูงสุด 3818.00 (+1,800 Points) | SL ของ Buy ถูกเลื่อนตามไปอีก (ล็อกประมาณ 20% ของกำไร) |
| 5 | ราคาย้อนลงมา 3813.00 (ย้อน 500 Points จากจุดสูงสุด) | Trailing TP ปิด Buy ที่ +$13 |
| 6 | ผลของรอบ | +$13 และ -$10 = ประมาณ +$3 |
| 7 | ตะกร้าว่าง | รอ Timeout 300 วินาที แล้วเปิดรอบใหม่ถ้าสเปรดผ่าน |

ถ้าราคาไปทางเดียวถึง +2,000 Points (3820.00) แบบไม่ย้อนเลย R:R ปิด Buy ที่ +$20 รอบนั้นสุทธิประมาณ +$10

### 4.3 รอบที่ราคาแกว่งไปมา (ตัวเลขสมมติ)

เปิดคู่ที่ 3800.00 ราคาขึ้นไป 3810.00 Sell ชน SL (-$10) แล้วราคาย้อนกลับลงมาโดนจุด SL ที่ถูกเลื่อนขึ้นมาล็อกกำไรของ Buy ที่ประมาณ +$2 สุทธิประมาณ -$8 ต่อรอบ ถ้าตลาดแกว่งแคบแบบนี้ซ้ำหลายรอบ จะขาดทุนสะสม ทุนเสมือนลดลง ซึ่งนี่คือความเสี่ยงหลักของกลยุทธ์ ควรดูแถว Closed Net และ Virtual Equity เป็นระยะ

ถ้าอยากพักช่วงตลาดผันผวน: กด OFF (ไม้ที่ค้างยังถูกดูแล) หรือใช้ Session Block

### 4.4 อยากพักเปิดรอบใหม่ชั่วคราว (เช่น ก่อนข่าวแรง)

1. กด OFF ที่มุมบนขวา Entry จะขึ้น `PAUSED`
2. ไม้ที่ค้างอยู่ยังถูกดูแลและปิดตาม SL หรือเป้าตามปกติ
3. ปุ่ม HEDGE OPEN ใช้ไม่ได้ จะขึ้นข้อความ `HEDGE ENTRY BLOCKED` ต่อท้ายว่า `PAUSED` ใน Log
4. เมื่ออยากกลับมา กด ON

ถ้าอยากเลิกถือไม้ทั้งหมดด้วย: กด CLOSE ALL

### 4.5 ทุนเสมือนหมด

ขาดทุนสะสมจนทุนเสมือนเหลือ 0 หรือติดลบ Entry ขึ้น `CAPITAL_DEAD` และ EA หยุดเปิดรอบใหม่

1. กด REFILL ที่ละ `InpRefillAmount` (ค่าเริ่มต้น $10) จนทุนเสมือนเป็นบวก
2. Entry กลับเป็น `WAIT_TIMEOUT` แล้ว `READY`
3. ถ้าใช้ Lock Profit ใช้ RESET เพื่อเติมกลับเท่าทุนเริ่มต้นในครั้งเดียว

หมายเหตุ: REFILL เพิ่มเฉพาะทุนเสมือนที่บอทนับ ไม่ได้ฝากเงินเข้าบัญชีจริง

### 4.6 สเปรดกว้างช่วงข่าวหรือช่วงตลาดเปลี่ยนวัน

Entry ขึ้น `WAIT_SPREAD` และ Panel แสดงสเปรดสูงกว่าเพดาน (เช่น `45 / Trigger 25 (ON)`) ระบบจะไม่เปิดรอบอัตโนมัติจนสเปรดลง

- ถ้าสเปรดของโบรกเกอร์สูงเกินเพดานเป็นปกติ: เพิ่ม `InpMaxSpreadPoints` อย่างระวัง หรือปิดตรวจสเปรดด้วย `InpUseSpreadCheck = false` (ต้นทุนต่อรอบจะสูงขึ้น)
- ปุ่ม HEDGE OPEN ข้ามเงื่อนไขสเปรดได้ ใช้เมื่อยอมรับต้นทุนเอง

### 4.7 ไม่อยากเปิดรอบในบางช่วงเวลา (Session Block)

ตัวอย่าง: ไม่อยากให้เปิดรอบใหม่ตอน 21:00 ถึง 24:00 เวลาเซิร์ฟเวอร์

1. ตั้ง `InpSession3Block = true` (เวลาเริ่ม 21:00 เวลาจบ 24:00 เป็นค่าเริ่มต้นอยู่แล้ว)
2. ในช่วงนั้น Panel แสดง `Session: BLOCK` และ Entry เป็น `SESSION_BLOCK`
3. ไม้ที่ค้างอยู่ยังถูกดูแลตามปกติ ปุ่ม HEDGE OPEN ยังกดได้
4. พ้นช่วงแล้ว ระบบเปิดรอบใหม่ตามเงื่อนไขปกติ (Timeout, สเปรด, ทุน)

### 4.8 ไม่อยากถือไม้ค้างข้ามช่วง (Session Close) ตัวอย่างช่วง rollover

ปัญหา: ไม้ค้างข้ามช่วง rollover อาจเสียค่าสวอป Session Block อย่างเดียวไม่ปิดไม้ที่ค้างอยู่ ต้องเปิด Session Close ด้วย

1. ตั้ง `InpSession3Block = true` และ `InpSession3Close = true` (ช่วง 21:00 ถึง 24:00 เวลาเซิร์ฟเวอร์)
2. ถึง 21:00 ใน Experts ต้องเห็น `SESSION-CLOSE START` ตามด้วย `SESSION-CLOSE DONE` และ Active เป็น 0
3. ปิดครั้งเดียวต่อช่วง รีสตาร์ท EA กลางช่วงไม่ปิดซ้ำ ปุ่ม HEDGE OPEN ที่กดหลังจากนั้นในช่วงเดียวกันไม่ถูกปิด
4. ถ้าแนบหรือรีสตาร์ท EA กลางช่วงที่ยังไม่เคยจัดการ และมีไม้ค้าง ไม้จะถูกปิดทันที
5. ปิดไม่หมด (เช่น โบรกเกอร์ปฏิเสธ) Log ขึ้น `CRITICAL - SESSION-CLOSE ปิดไม่หมด` และลองใหม่ทุก 5 วินาที
6. ทำงานแม้ปุ่มเป็น OFF (OFF ห้ามเปิดใหม่ ไม่ได้ห้ามปิด)

ถ้าตั้ง Close เป็น true แต่ลืมเปิด Block: ตอนเริ่ม EA มีข้อความเตือน และตัวเลือกไม่ทำงาน

### 4.9 ปิดไม้เองจากมือถือหรือแท็บ Trade

ปิดไม้ของ Hedge ด้วยตัวเอง (เช่น จากมือถือ) ได้ ระบบดูแลตะกร้าต่อ และถ้า `InpCountExternalClose = true` (ค่าเริ่มต้น) กำไรขาดทุนจากการปิดนั้นถูกนับเข้า Closed Net และทุนเสมือนทันที

ตัวอย่างที่ทดสอบแล้ว: ปิดขาเดียวด้วยมือแล้ว Closed Net เปลี่ยนจาก +0.00 เป็น -0.58 ทันที ถ้าตั้ง `InpCountExternalClose = false` ตัวเลขกลับไม่รวมขานั้น

ระวัง: ยอดคำนวณจากประวัติทั้งหมด หากอัปเดตจากรุ่นก่อนหน้า ตัวเลข Closed Net และ Lot อาจเปลี่ยนตอนเริ่ม EA เพราะย้อนนับการปิดนอก EA ในอดีตของ Magic นั้นด้วย จดค่าก่อนอัปเดตไว้เทียบ

### 4.10 โหมด Lock Profit (กำไรไม่เพิ่มทุนเทรด)

ตั้ง `InpLockProfit = true` เมื่ออยากให้ Lot โตตามกำไรไม่ได้ ขาดทุนเท่านั้นที่ลดทุนเทรด

- Panel เปลี่ยนป้ายเป็น Trading Cap และ Locked Profit และมีปุ่ม RESET
- ตัวอย่างที่ทดสอบ: ปิดขา Buy กำไร +0.46 Locked Profit เป็น +0.46 แต่ Trading Cap คงที่ที่ $50.00 ปิดขา Sell ขาดทุน Trading Cap ลดลงตามขาดทุน
- ระบบคิดผลสุทธิ "ต่อไม้" แล้วนับเฉพาะไม้ที่สุทธิติดลบมาลดทุน
- ใช้ RESET เมื่ออยากเติมทุนเทรดกลับเท่าทุนเริ่มต้น

เมื่อเปลี่ยนค่านี้ ต้องกด OK ในหน้า Inputs และตรวจว่า Panel เปลี่ยนป้ายจริง ถ้าไม่เปลี่ยน แปลว่าค่ายังไม่ถูกใช้

### 4.11 ใช้โหมดมือ (เปิดคู่เองทุกรอบ)

1. ตั้ง `InpReopenOnEmpty = false`
2. Entry ขึ้น `AUTO_OFF` เมื่อตะกร้าว่าง EA จะไม่เปิดเอง
3. กด HEDGE OPEN เมื่อพร้อม ปุ่มนี้ข้าม Session, Timeout และสเปรด แต่ไม่ข้าม OFF, รายงานค้าง และทุนหมด
4. ระบบป้องกันยังดูแลไม้เหมือนเดิม

### 4.12 รีสตาร์ท EA หรือเปลี่ยนไทม์เฟรมขณะมีไม้ค้าง

ไม้ที่ค้างอยู่ไม่ถูกปิด EA กลับมาดูแลต่อ สถานะสำคัญถูกจำไว้ ได้แก่ ยอด REFILL, รอบรายงาน, กำไรสูงสุดของ Trailing, สถานะ ON/OFF และฐานของรอบ ใน Log เห็น `LOCK RELEASED` ตามด้วย `LOCK ACQUIRED` และ `เริ่มระบบสำเร็จ`

### 4.13 รายงานไฟล์ CSV

เมื่อครบ `InpReportDays` วัน และตะกร้าว่างนิ่งอย่างน้อย 2 วินาที ระบบสร้างไฟล์ในโฟลเดอร์ `MQL5\Files` ชื่อรูปแบบ `HDG_<คู่เงิน>_<บัญชี>_<Magic>_FROM_<เวลา>.csv` คอลัมน์: Date, ClosedPL, ClosedTrades, TradedLots, PeriodCumNet พร้อมแถว TOTAL

ระหว่างทำรายงาน Entry ขึ้น `WAIT_REPORT` และไม่เปิดรอบใหม่ ถ้ายังมีไม้ค้างจะรอให้ปิดหมดก่อน

### 4.14 จำกัดจำนวนรอบอัตโนมัติ (กันตลาดไซด์เวย์)

ปัญหา: ตลาดแกว่งแคบ Hedge เปิดรอบใหม่ซ้ำๆ แล้วโดน SL ต่อเนื่องจนทุนเสมือนหมด วิธีกัน: ตั้ง `InpMaxAutoRounds` เป็นจำนวนรอบอัตโนมัติสูงสุดต่อช่วง (0 = ไม่จำกัด) และเปิด Session Block อย่างน้อยหนึ่งช่วงเพื่อใช้เป็นจุดรีเซ็ต

ตัวอย่าง: ตั้ง `InpSession1Block = true` ช่วง 01:00 ถึง 04:00 และ `InpMaxAutoRounds = 2`
1. ถึง 04:00 (ช่วง Block จบ) โควต้าเริ่มใหม่ เปิดรอบที่ 1 ตอน 04:20 แถว Entry ขึ้น `BASKET_RUNNING 1/2` (ตัวเลขแรกคือรอบที่ใช้ไป ตัวเลขหลังคือโควต้าที่ตั้ง)
2. เปิดรอบที่ 2 ตอน 05:40 ตัวนับเป็น `2/2`
3. หลังรอบที่ 2 ปิด Entry ขึ้น `QUOTA_DONE 2/2` และ Hedge ไม่เปิดรอบอัตโนมัติอีก
4. ถึง 04:00 วันถัดไป โควต้ารีเซ็ตเอง ถ้าตั้ง Block ช่วงเดียว นี่คือ "N รอบต่อวัน" เปิด Block หลายช่วงถ้าอยากรีเซ็ตหลายครั้งต่อวัน

สิ่งที่ควรรู้:
- รอบที่ N ที่เปิดแล้วจะวิ่งจนจบตามปกติ ระบบป้องกันและ CLOSE ALL ไม่ถูกกระทบ
- ปุ่ม HEDGE OPEN ไม่นับโควต้าและกดได้แม้หมดโควต้า ปุ่ม OFF ยังเป็นสวิตช์บล็อกทุกทาง (หมดโควต้าแล้วกด OFF จะขึ้น PAUSED by user)
- แถว Entry แสดงตัวนับ `n/N` ต่อท้ายสถานะ ยกเว้นตอน READY ซึ่งไม่มีตัวเลข (เพื่อให้สีเขียวคงเดิม)
- รีสตาร์ท EA ตัวนับไม่หาย ถ้า EA ดับข้ามเวลาจบ Block จะรีเซ็ตทันทีตอนเริ่มใหม่
- ถ้าไม่เปิด Session Block เลย โควต้าไม่รีเซ็ตเอง Log เตือนตอนเริ่ม ต้องรีเซ็ตมือโดยลบตัวแปร Global ลงท้าย `_QN` และ `_QE` ของ Magic นั้นใน MT5 (F3) แล้วรีสตาร์ท EA
- โควต้านับ "จำนวนรอบ" ไม่ได้นับ "จำนวนเงิน" ที่ค่าเริ่มต้นบนทอง 0.01 Lot รอบที่แย่สุดเสียประมาณ $20 ดังนั้น 2 รอบอาจเสียได้ถึงประมาณ $40 จากทุน $50 ควรดู Closed Net และ Virtual Equity ควบคู่

## 5. ตารางสรุป: อยากทำอะไร ใช้อะไร

| อยากทำ | ใช้อะไร | หมายเหตุ |
|---|---|---|
| เปิดรอบเองตอนนี้ | HEDGE OPEN | ข้าม Session, Timeout, สเปรด |
| ให้เปิดรอบเองเฉพาะตอนกด | `InpReopenOnEmpty = false` | Entry ขึ้น AUTO_OFF |
| พักเปิดรอบใหม่ แต่ไม่ปิดไม้ที่ถือ | ปุ่ม OFF | ระบบป้องกันยังทำงาน |
| เลิกถือทั้งหมดทันที | CLOSE ALL | ใช้ได้ตลอด |
| ปิดเฉพาะฝั่ง | CLOSE BUY หรือ CLOSE SELL | เหลือขาเดียว ต้องรอปิดหมดก่อนเปิดรอบใหม่ |
| ทุนหมด เปิดรอบไม่ได้ | REFILL | เติมทุนเสมือนครั้งละ `InpRefillAmount` |
| จำกัดจำนวนรอบอัตโนมัติ กันตลาดไซด์เวย์ | `InpMaxAutoRounds` + Session Block | 0 = ไม่จำกัด รีเซ็ตเมื่อ Block สิ้นสุด |
| ลดความเสี่ยงต่อไม้ | ลด `InpCutLossPoints` | ต้องมากกว่า 0 |
| จำกัดขนาด Lot | `InpMaxLotStep`, หรือปิด `InpAutoLot` | 0 = ไม่จำกัดเพดาน |
| ไม่ให้เปิดรอบในช่วงเวลาหนึ่ง | `InpSessionNBlock` | ไม้ที่ค้างยังดูแลต่อ |
| ไม่ให้ถือไม้ข้ามช่วงเวลา | `InpSessionNBlock` + `InpSessionNClose` | ปิดตอนเริ่มช่วง |
| ตัวเลขทุนตรงแม้ปิดไม้เองนอก EA | `InpCountExternalClose = true` | ค่าเริ่มต้น |
| Lot ไม่โตตามกำไร | `InpLockProfit = true` | มีปุ่ม RESET |
| เห็น WAIT_SPREAD บ่อย | ปรับ `InpMaxSpreadPoints` | ดูสเปรดจริงของโบรกเกอร์ก่อน |
| อยากรอรอบละหลายนาที | `InpTimeoutSeconds` | ค่าเริ่มต้น 300 |
| อยากได้ไฟล์สรุปกำไรขาดทุน | `InpEnableReport`, `InpReportDays` | ไฟล์ CSV ใน MQL5\Files |
| แนบ EA หลายกราฟ | แยก `InpMagicNumber` ต่อกราฟ | ห้ามซ้ำ |

## 6. อ่าน Log ในแท็บ Experts

| ข้อความ | แปลว่า |
|---|---|
| `เริ่มระบบสำเร็จ` และ `Strategy=Hedge 1.0 v1.0.1` | EA เริ่มทำงานปกติ บอกรุ่นและ Magic |
| `AUTO READY -> เปิด Hedge ใหม่` | ประตูผ่านแล้ว เริ่มเปิดรอบอัตโนมัติ |
| `CYCLE START` พร้อมค่า `Baseline` | เริ่มรอบใหม่ จดฐานกำไรสุทธิไว้ใช้คำนวณ Cycle Loss |
| `เปิดคู่ Hedge สำเร็จจริง` | ตรวจแล้วว่ามี Buy 1 ไม้ Sell 1 ไม้ Lot เท่ากัน |
| `[HEDGE] slippage N pts` | ราคาที่ได้จริงต่างจากที่ขอ N Points (ปกติ ไม่ใช่ความผิดพลาด) |
| `[CUTLOSS-SL] แก้ SL สำเร็จจริง` | ระบบปรับ SL ตามราคาเข้าจริง |
| `[BREAK-EVEN] แก้ SL สำเร็จจริง` | ระบบเลื่อน SL มาล็อกกำไร |
| `Trailing TP ARMED / CLOSE`, `[RR]` | เริ่มจับกำไร / ปิดตามเป้า |
| `[CLOSE-ALL] ปิดไม้ ... สำเร็จจริง` | ปิดจากปุ่ม CLOSE ALL |
| `SESSION-CLOSE START` และ `SESSION-CLOSE DONE` | ปิดไม้ตอนเริ่ม Session ตามที่ตั้ง |
| `CRITICAL - SESSION-CLOSE ปิดไม่หมด` | ปิดไม้ตอนเริ่ม Session ไม่ครบ ลองใหม่ทุก 5 วินาที ควรดูทันที |
| `HEDGE ENTRY BLOCKED` ต่อท้ายว่า `PAUSED` | กด HEDGE OPEN ตอนปุ่มเป็น OFF |
| `HEDGE ROLLBACK` | เปิดคู่ไม่สมบูรณ์ ระบบปิดทิ้ง |
| `CRITICAL - HEDGE ROLLBACK ปิดไม่หมด` | ปิดทิ้งไม่หมด ต้องดูไม้ที่ค้างด้วยตัวเองทันที |
| `CSV COMPLETE` | สร้างไฟล์รายงานสำเร็จ |
| `QUOTA USED n/N` | นับรอบอัตโนมัติที่เปิดคู่สำเร็จ |
| `QUOTA_DONE` | หมดโควต้ารอบอัตโนมัติ รอ Session Block สิ้นสุด |
| `QUOTA RESET` | ช่วง Session Block สิ้นสุด ตัวนับกลับเป็น 0 |
| `LOCK ACQUIRED` / `LOCK RELEASED` | ล็อกกันแนบ EA ซ้ำ Magic เดียวกัน (ปกติเห็นตอนเริ่มและปิด EA) |

## 7. ข้อจำกัดและข้อควรระวัง

- ไม่รับประกันกำไร ในกรณีเลวร้ายทั้งสองไม้ชน SL
- รองรับบัญชี Hedging เท่านั้น บัญชี Netting จะถูกปฏิเสธตอนเริ่ม
- ค่ามาตรฐานตั้งไว้สำหรับทอง ถ้าใช้สัญลักษณ์อื่น ต้องตั้ง `InpPointDigits` และระยะ Points ใหม่เอง
- ล็อกกันแนบซ้ำไม่ข้ามเทอร์มินัล (กันเฉพาะในเทอร์มินัลเดียวกัน) อย่าแนบ Magic เดียวกันจากเทอร์มินัลอื่นกับบัญชีเดียวกัน
- ไฟล์ชุดค่า `.set` ที่ชื่อ `SHORT_*` เป็นชุดทดสอบระยะสั้น (เช่น Cut Loss 70 Points) ไม่ใช่ค่าแนะนำสำหรับเทรดจริง
- v1.0.1 ยังเป็นสำเนาทดสอบ ผลทดสอบทั้งหมดมาจากบัญชี Demo ที่ยังไม่ได้ทดสอบ: ไฟล์ CSV เทียบ Closed Net, กรณีปิดไม่หมดแล้วลองใหม่ และช่วงข้ามเที่ยงคืนบนกราฟจริง
- ค่า Magic และช่วงเวลาที่ใช้ทดสอบ (เช่น Timeout 60 วินาที) เป็นค่าชั่วคราว ไม่ใช่ค่าแนะนำ
- รายละเอียดเชิงเทคนิคและการตัดสินใจออกแบบ: `Strategies/Hedge/doc/README.md` และ `docs/decisions/D-30_session_close_and_external_close.md`
